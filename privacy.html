CloudPlayer プライバシーポリシー

制定日: 2026年10月29日 ・ 更新日: 2026年11月1日(歌詞ファイルの保存・タグの書き込み・ジャケットの検索を追加) ・ CloudPlayer のホームページ

CloudPlayer(以下「本アプリ」)は、Google ドライブに置いた音楽を再生するための個人用の Android アプリです。 本アプリが扱う情報と、その扱い方を説明します。

1. Google ドライブのデータ

  • 本アプリは、Google ドライブの読み取り専用の権限(drive.readonly)を使い、利用者が選んだフォルダにある音楽ファイルと、その名前・大きさ・更新日時などの情報を読み込みます。
  • 読み込んだ情報は、曲の一覧・再生・ダウンロード・歌詞の表示・曲の解析のためだけに、利用者の端末の中で使います。
  • ドライブへの書き込み: 利用者が次の操作をしたときに限り、Google ドライブ全体の読み書きの権限(drive)を追加で求め、次の目的だけに使います。 ふだんの同期・再生・ダウンロードでは、引き続き読み取り専用の権限だけを使います。
    • 「Drive に .lrc を保存」: 編集した歌詞を、その曲と同じフォルダに歌詞ファイル(.lrc)として作成または更新します。
    • 「タグを編集」: 編集した曲名・アーティスト・アルバム・番号・年・ジャンル・ジャケットを、アプリで同期しているフォルダの中の元の曲のファイル(FLAC と MP3)に書き込みます。書き換える前の内容は、約 30 日間 Google ドライブの版の履歴に残ります。
    これ以外のファイルの作成・変更・削除・共有には使いません。
  • バックアップ: 本アプリは、Google ドライブのアプリ専用領域の権限(drive.appdata)も使います。 アプリ内で作ったプレイリスト・グループ・お気に入り・評価・再生の履歴・Web から取得した歌詞・曲の解析結果・設定・同期するフォルダの控え(バックアップ)を、 利用者自身の Google ドライブのアプリ専用領域(ドライブの画面には表示されず、本アプリだけが読み書きできる領域)に保存し、 戻すときに読み込み、古い控えを削除するためだけに使います。 控えには音楽ファイル、アカウント情報、アクセストークン、位置や天気の情報は含めません。 自動の控えは設定の「バックアップ」でオフにでき、控えはその画面から削除できます。 Google ドライブの設定の「アプリの管理」から、本アプリの隠しデータを削除することもできます。
  • Google ドライブから得たデータを、本アプリの開発者や第三者のサーバーへ送ることはありません。広告や販売、利用者の追跡には使いません。

2. 端末に保存する情報

  • 曲の一覧と曲の情報、ダウンロードした音楽ファイル、プレイリスト、お気に入り、評価、再生の履歴、曲の解析結果、設定は、利用者の端末の中に保存します。
  • 曲の解析(雰囲気やテンポの推定)は端末の中で行い、結果を外部へ送りません。
  • Android の自動バックアップを有効にしている場合、上の情報の一部(ダウンロードした音楽ファイルを除く)は、Android の仕組みにより利用者自身の Google アカウントにバックアップされることがあります。位置や天気の情報はバックアップの対象から外しています。
  • 本アプリを端末から削除すると、端末に保存した情報も消えます。

3. 外部のサービスに送る情報

  • 天気(Open-Meteo): 「天気を使う」がオンで、おおよその位置の利用を許可した場合だけ、端末のおおよその位置を小数第 1 位(約 10 km)に丸めて Open-Meteo に送り、今の天気を受け取ります。位置は保存せず、送るのは丸めた値だけです。設定でいつでもオフにできます。
  • 歌詞(LRCLIB): 歌詞を探すときに、曲名・アーティスト名・アルバム名・曲の長さを LRCLIB に送ります。
  • ジャケットの検索(iTunes Search API・MusicBrainz・Cover Art Archive): 利用者がジャケットを探したときだけ、入力されたアルバム名とアーティスト名を、画像の候補を探すために Apple の iTunes Search API(itunes.apple.com)と MusicBrainz(musicbrainz.org)に送ります。候補の画像は、Apple の画像サーバーと Cover Art Archive(画像は archive.org から配信)から取得します。アカウント・曲のファイル・位置などのほかの情報は送りません。
  • Google: Google アカウントでのログイン、Google ドライブの読み込み、利用者自身の Google ドライブのアプリ専用領域へのバックアップ、上に書いた歌詞ファイルの保存とタグの書き込みのために、Google のサービスと通信します。

上記のほかに、広告や分析のためのサービスは使っていません。

4. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用と他のアプリへの転送は、 Google API Services User Data Policy (Limited Use の要件を含む)に従います。

5. 権限の取り消し

Google アカウントのサードパーティのアクセスの画面から、 いつでも本アプリへのアクセスを取り消せます。位置の許可は、Android の設定から取り消せます。

6. このポリシーの変更

内容を変えるときは、このページを更新し、制定日の横に更新日を記します。
